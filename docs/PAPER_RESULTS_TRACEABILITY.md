# Paper Results Traceability

How any number produced by this repository traces back to (a) the baseline
algorithm, (b) a specific input, and (c) a specific software environment.
The table/figure ↔ script mapping lives in
`configs/paper_results_mapping.md`; this document defines the chain of
evidence.

## Chain of evidence

```
paper number
  <- results/tables/*.csv  (row)
     <- results/logs/*.json (record: config snapshot + per-input metrics)
        <- input file       (identified by SHA3-256 in the same log)
        <- runtime env      (python/numpy/scipy/matplotlib/aghc-s128 versions)
        <- algorithm        (aghc_s128 code == baseline, proven below)
```

### Algorithm ↔ baseline

`tests/test_regression_baseline.py` proves byte-identity against
`tests/baseline_reference.py` (frozen verbatim port of the original Colab
notebook cell 0) on 13 cipher vectors covering: n ∈ {2, 4, 8}, sizes 0..64
including `< N`, `== N`, multiples of `N`, and mixed Hill+residual; one
vector with trial index 5 (retry path).  Metric formulas are checked against
verbatim notebook implementations on fixed byte patterns, including the
notebook's silent-truncation behavior (`allow_truncate=True`).

**Known deviations** (documented, intentional, minimal):

| Deviation | Where | Why | Impact |
|---|---|---|---|
| Monobit unsigned underflow fixed | `metrics.monobit_frequency_test` | notebook's numpy unsigned `ones - zeros` wraps when zeros > ones, forcing p = 0 | only affects monobit p-values for zeros>ones streams; all other metrics unchanged (KNOWN_ISSUES K-8) |
| Length-mismatched paired metrics raise instead of truncating | `npcr`/`uaci`/`bit_difference_ratio`/`key_sensitivity` | silent truncation produced ill-defined numbers | none for equal-length pairs (the only well-defined case in this cipher) |

Everything else — key construction, trial retry, reshape orientation,
Shift-128, all metric formulas — is byte-identical.

### Input ↔ log

`run_*` runners embed per-input SHA3-256 and size in the JSON log; the CSV
row inherits the log filename in its `log_file` column.

### Environment ↔ log

Every log embeds `runtime_environment` (Python, OS, numpy/scipy/matplotlib
and package versions) and a UTC timestamp.

## What cannot (yet) be traced to the paper

`[BUTUH INPUT PENULIS]`

1. **Exact paper tables/figures** — the paper's table and figure numbering,
   captions, and published numeric values have not been provided in
   machine-readable form.  Once provided, add a comparison column to the
   mapping in `configs/paper_results_mapping.md` and, where original inputs
   exist, a diff report `results/tables/paper_vs_reproduced.csv`.
2. **Original input datasets** — see `docs/DATASET_SOURCES.md` and
   `data/manifest.csv`; pipelines covering them currently run on synthetic
   samples and are marked `[PENDING ORIGINAL INPUT DATA]`.
3. **Original runtime environment** — the Colab session(s) used for the
   paper (Python/library versions, GPU/TPU, CPU model) are not recorded in
   the notebook; runtime comparisons are therefore indicative only.
4. **Author metadata for citation** — see `CITATION.cff` placeholders.

## Rules for adding paper numbers

* Never paste paper numbers into generated CSVs — pipelines only ever write
  values they computed.
* Comparisons live in clearly-named separate artifacts
  (e.g. `paper_vs_reproduced.csv`) generated by hand or a dedicated script,
  with the paper source (page/table) noted in a comment column.
* Any mismatch between paper and reproduced values is reported, not hidden;
  investigate data, environment, or notebook-version differences.
