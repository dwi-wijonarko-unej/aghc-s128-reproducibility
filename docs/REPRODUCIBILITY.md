# Reproducibility Guide

## Guarantee levels

| Level | What is guaranteed | How it is enforced |
|---|---|---|
| **Byte-exact cipher behavior** | Ciphertexts, key matrices, trial indices identical to the original Colab baseline for any (password, n, input) | `tests/test_regression_baseline.py` against fixtures generated from the frozen baseline reference |
| **Byte-exact metric values** | Entropy/correlation/NPCR/UACI/bit-difference/chi-square identical to the notebook formulas (one documented exception: monobit underflow fix, KNOWN_ISSUES K-8) | same regression suite |
| **End-to-end pipeline** | demo/experiment runs re-executable from shipped configs + samples | `scripts/*`, `configs/*.yaml`, CLI |
| **Paper tables/figures** | reproducible **only** where original datasets are available; otherwise pipeline-level demonstration | `configs/paper_results_mapping.md` status column |

## Quick reproduction (2 minutes)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .[test]
python -m pytest tests/                     # must be green
python scripts/run_quick_demo.py            # full pipeline on a sample
```

Outputs land in `results/example_outputs/` (log JSON, CSV row, histogram +
entropy figures).  The demo password is a public test vector stored in
`configs/quick_demo.yaml`.

## Environment snapshot

Every experiment log embeds:

* Python version + implementation, OS, machine architecture;
* numpy / scipy / matplotlib / aghc-s128 versions;
* UTC timestamp of the run;
* full config snapshot and SHA3-256 of every input.

See `docs/COMPUTATIONAL_ENVIRONMENT.md` for the reference environment used
during development and how to recreate it (pip, conda, and Colab).

## Reproducing an analysis by hand

```bash
export AGHC_PASSWORD='your-test-password'

# encrypt + decrypt with metadata sidecar
aghc-s128 encrypt data/sample/sample_text.txt --n 8 --output /tmp/t.enc

# Mode A statistical analysis (original vs encrypted [+ decrypted])
aghc-s128 analyze data/sample/sample_text.txt /tmp/t.enc \
    --decrypted /tmp/t_encrypted_decrypted.txt \
    --output-dir results/analysis

# Mode B key sensitivity between two ciphertexts
aghc-s128 key-sensitivity cipherA.bin cipherB.bin --output-dir results/analysis
```

Password handling: environment variable (default `AGHC_PASSWORD`) or
`--prompt` (getpass).  The CLI never accepts a password as a command-line
argument, so it cannot leak into shell history.

## Determinism notes

* The cipher is fully deterministic given (password, n, input bytes).
* The perturbation uses an isolated `random.Random(seed)` whose stream is
  identical to the baseline's global `random.seed(seed)` (regression-tested).
* The logistic map stays a pure-Python scalar loop; float behavior follows
  IEEE-754 doubles (KNOWN_ISSUES K-4).
* Wall-clock runtimes vary by hardware and load; they are recorded as
  metadata, never compared to paper values as pass/fail.

## What can differ from the paper's numbers

1. **Different input files** (samples vs original datasets) — every metric
   except round-trip/integrity is data-dependent.
2. **Monobit p-values** — corrected underflow (K-8) changes verdicts only
   where the notebook's arithmetic wrapped around (zeros > ones).
3. **Runtimes** — different hardware.
4. **Colab library versions** — scipy `pearsonr`/`chisquare` results are
   stable across supported versions; if a future scipy changes them, the
   pinned requirements protect reproduction.

## Regression fixtures

`tests/fixtures/test_vectors.json` is generated by
`tests/fixtures/generate_test_vectors.py`, which executes the frozen
`tests/baseline_reference.py`.  To regenerate after an *intentional*,
documented baseline change:

```bash
python tests/fixtures/generate_test_vectors.py
git diff tests/fixtures/test_vectors.json   # review every changed value
```

Unintended changes fail the regression suite — do not regenerate fixtures to
"fix" a failing test without understanding the divergence.
